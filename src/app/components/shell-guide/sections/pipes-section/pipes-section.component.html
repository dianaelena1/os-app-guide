10. Pipes & FIFO

Pipe-urile permit comunicarea între procese. Un pipe este un canal unidirecțional: un proces scrie date, iar alt proces le citește.

pipe()

1. What is a Pipe?

Un pipe este un canal de comunicare între procese. Datele sunt scrise într-un capăt și citite din celălalt capăt.

Process 1 scrie
write() fd[1]
PIPE
read() fd[0]
Process 2 citește
Important: un pipe normal permite comunicare într-o singură direcție.

2. pipe()

Funcția pipe() creează doi descriptori de fișier: unul pentru citire și unul pentru scriere. 

#include <unistd.h>

int fd[2];

if (pipe(fd) == -1) {
    perror("pipe");
    return 1;
}
fd[0] capătul de citire al pipe-ului
fd[1] capătul de scriere al pipe-ului

3. How Pipes Work

Pipe-ul funcționează ca o coadă: primul mesaj scris este primul mesaj citit. De aceea spunem că respectă principiul FIFO: First In, First Out.

1 write(fd[1])
2 Kernel buffer
3 read(fd[0])
Datele nu merg automat înapoi. Pentru răspuns în direcția opusă ai nevoie de un al doilea pipe.

4. Pipe + fork()

De obicei, pipe-ul este creat înainte de fork(). După fork(), atât părintele cât și copilul au acces la aceiași descriptori fd[0] și fd[1].

Parent fd[0] fd[1]
fork()
PIPE
Child fd[0] fd[1] 
int fd[2];
pipe(fd);

pid_t pid = fork();

5. read() / write()

După fork(), fiecare proces trebuie să închidă capătul pe care nu îl folosește. Altfel, programul se poate bloca.

Procesul care citește închide capătul de scriere close(fd[1]);
Procesul care scrie închide capătul de citire close(fd[0]);

Writer

close(fd[0]);

char msg[] = "Salut";
write(fd[1], msg, strlen(msg) + 1);

close(fd[1]);

Reader

close(fd[1]);

char buffer[100];
read(fd[0], buffer, sizeof(buffer));

close(fd[0]);

6. FIFO

FIFO înseamnă named pipe. Spre deosebire de un pipe normal, FIFO are un nume în sistemul de fișiere și poate fi folosit între două programe diferite, de exemplu un client și un server.

Program A
open()
fifo1
open()
Program B

7. mkfifo()

Funcția mkfifo() creează un FIFO în sistemul de fișiere. După aceea, acesta poate fi deschis cu open(). 

#include <sys/stat.h>
#include <fcntl.h>
#include <unistd.h>

mkfifo("fifo1", 0666);

Server - citește

int fd = open("fifo1", O_RDONLY);

char buffer[100];
read(fd, buffer, sizeof(buffer));

close(fd);

Client - scrie

int fd = open("fifo1", O_WRONLY);

char msg[] = "Salut server";
write(fd, msg, strlen(msg) + 1);

close(fd);

8. Common Exam Mistakes

read(fd[1]) Greșit: fd[1] este pentru scriere.
write(fd[0]) Greșit: fd[0] este pentru citire.
Uiți close() Programul poate rămâne blocat în read().
Uiți wait() Procesul copil poate deveni zombie.
Un singur pipe pentru două direcții Pentru comunicare bidirecțională ai nevoie de două pipe-uri.
