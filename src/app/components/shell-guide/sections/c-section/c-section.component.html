8. C PROGRAMMING

Limbajul C este procedural, modular și foarte folosit pe Unix/Linux, mai ales pentru programe aproape de sistem.

C

1. Cum scriem și rulăm un program C

1 Source file program.c
2 Compile gcc program.c
3 Run ./a.out
4 Output Hello, C!

2. Structura unui program C

#include <stdio.h>

int main() {
    printf("Hello, C!\n");
    return 0;
}

Execuția începe din funcția main().

3. Memorie vs fișiere

Main memory temporar

Datele se pierd după terminarea programului.

File permanent

Datele pot fi păstrate pentru utilizare viitoare.

8. Command-line arguments

int main(int argc, char *argv[]) {
    printf("Program name: %s\n", argv[0]);

    if (argc > 1) {
        printf("First argument: %s\n", argv[1]);
    }

    return 0;
}

9. File handling example

FILE *f = fopen("data.txt", "r");

if (f == NULL) {
    printf("File could not be opened\n");
    return 1;
}

fclose(f);

10. Practice

  • Primește numele unui fișier ca argument și afișează conținutul.
  • Numără câte linii are fișierul.
  • Primește un fișier și un string și adaugă string-ul la final.
  • Copiază conținutul dintr-un fișier în altul.

Atenție: în C trebuie să verifici mereu dacă fișierul s-a deschis corect. Dacă fopen() returnează NULL, fișierul nu poate fi folosit.
