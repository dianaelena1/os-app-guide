5. Linux GREP Cheatsheet

grep este o comandă Unix folosită pentru a căuta un pattern de text într-un fișier sau într-un flux de date.

grep

grep = g/re/p

g global /re/ regular expression p print

1. Usage

grep [opțiuni] pattern [fișier]
grep "sequence" file_1.txt
grep sequence file_1.txt file_2.txt
echo "This is a test" | grep "is"

Pattern-ul poate fi un cuvânt simplu sau o expresie regulată. grep poate căuta într-un fișier, în mai multe fișiere sau în output-ul altei comenzi.

2. Opțiuni importante

-iignoră diferența dintre litere mari și mici
-rcaută recursiv în directoare
-lafișează doar numele fișierelor cu match
-cafișează numărul de potriviri
-wpotrivește doar cuvântul întreg
-nafișează și numărul liniei
-vafișează liniile care NU conțin patternul
-Efolosește expresii regulate extinse
-A nafișează n linii după match
-B nafișează n linii înainte de match
-C nafișează n linii înainte și după match

3. Wildcard-uri

.orice caracter
?zero sau un caracter
*zero sau mai multe caractere
+unul sau mai multe caractere

4. Poziții

^început de linie
$sfârșit de linie
^$linie goală
\blimită de cuvânt

5. Clase de caractere

[A-Z]litere mari
[a-z]litere mici
[0-9]cifre
[A-Za-z0-9]litere sau cifre
[^abc]orice caracter în afară de a, b, c

6. POSIX

[:alpha:]litere
[:digit:]cifre
[:alnum:]litere sau cifre
[:lower:]litere mici
[:upper:]litere mari
[:space:]spații
