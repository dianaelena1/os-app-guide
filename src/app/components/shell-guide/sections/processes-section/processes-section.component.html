9. Processes in C

În Linux, un proces este o instanță a unui program aflat în execuție. Fiecare proces are propriul PID, memorie proprie, descriptori de fișiere și poate crea procese copil folosind fork().

fork()

1. Ce este un proces?

Un proces rulează în spațiul utilizator și comunică cu sistemul de operare prin apeluri de sistem. Kernelul gestionează memoria, fișierele, driverele și mecanismele de comunicare între procese.

PIDProcess ID
PPIDParent Process ID
UIDUser ID
FDFile descriptors

2. Crearea unui proces cu fork()

Funcția fork() duplică procesul curent. După apel există două procese care continuă execuția: procesul părinte și procesul copil.

pid < 0 eroare la crearea procesului
pid == 0 cod executat în procesul copil
pid > 0 cod executat în procesul părinte
După apelul fork(), atât părintele cât și copilul continuă execuția din instrucțiunea următoare.

3. Așteptarea copilului cu wait()

Părintele folosește wait() pentru a aștepta terminarea procesului copil. Dacă părintele nu colectează copilul terminat, acesta poate rămâne temporar ca proces zombie. 

#include <sys/wait.h>

wait(NULL);
Pentru examen: dacă ai proces părinte și copil, verifică mereu unde trebuie pus wait(NULL).

4. Comunicarea prin semnale

Un semnal este un mesaj trimis de sistem sau de un proces către alt proces. Semnalele nu sunt folosite pentru transfer de date, ci pentru notificare sau control.

SIGTERMcere terminarea procesului
SIGKILLoprește forțat procesul
SIGSTOPsuspendă procesul
SIGCONTreia procesul suspendat

5. Ce se întâmplă când un proces primește un semnal?

Procesul poate executa acțiunea implicită, poate rula un handler personalizat sau poate ignora semnalul, dacă semnalul permite acest lucru.

Defaultse execută acțiunea implicită
Handlerse rulează o funcție proprie
Ignoreprocesul ignoră semnalul

6. Trimiterea semnalelor cu kill()

Funcția kill() trimite un semnal către un proces sau către un grup de procese. Numele poate induce în eroare: kill() nu omoară mereu procesul, ci trimite un semnal. 

#include <sys/types.h>
#include <signal.h>

int kill(pid_t pid, int sig);
