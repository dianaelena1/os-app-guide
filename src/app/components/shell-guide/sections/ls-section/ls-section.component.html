3. Linux DIRECTORY STRUCTURE

ls este comanda folosită pentru a afișa conținutul unui director. În Linux, directoarele pornesc de la /, numit și root.

🐧
Linux directory structure

1. Structura directoarelor Linux

/
bincomenzi și executabile de bază
bootfișiere necesare pentru pornirea sistemului
devfișiere pentru dispozitive
etcfișiere de configurare
homedatele utilizatorilor
libbiblioteci și module
mediamedii externe montate
mntpunct temporar de montare
optsoftware opțional
procprocese și informații despre kernel
roothome-ul utilizatorului root
tmpfișiere temporare
usrprograme și date pentru utilizatori
vardate variabile, de exemplu loguri

2. Sintaxă de bază

ls
ls folder/
ls file1 file2

3. Opțiuni utile

-lafișare detaliată
-aafișează și fișierele ascunse
-hdimensiuni ușor de citit
-ladetalii + fișiere ascunse
-Rlistare recursivă

4. Testează exemplele importante

ls
ls -l
ls -a
ls -la
ls -lh
ls /home/student
