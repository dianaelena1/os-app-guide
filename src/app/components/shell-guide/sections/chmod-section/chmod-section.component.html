4. Linux FILE PERMISSIONS

chmod modifică permisiunile unui fișier sau director: cine poate citi, scrie sau executa.

chmod

1. Cum citim permisiunile

- rwx rw- r--
- tip fișier
rwx user / owner
rw- group
r-- others

2. Valori numerice

Owner

7

rwx

4 + 2 + 1

Group

6

rw-

4 + 2 + 0

Other

4

r--

4 + 0 + 0

3. Ce înseamnă r, w, x?

rread4
wwrite2
xexecute1
-fără permisiune0

4. Mod simbolic

chmod u+x script.sh
chmod g-w file.txt
chmod o+r notes.txt
uuser / owner
ggroup
oothers
+adaugă permisiune
-elimină permisiune

5. Mod numeric

chmod 755 script.sh
chmod 644 report.txt
chmod 764 backup.sh

Fiecare cifră reprezintă suma permisiunilor pentru: owner, group, others.

6. Exemple explicabile rapid

chmod +x script.sh face scriptul executabil
chmod 755 script.sh owner: rwx, group: r-x, others: r-x
chmod 644 file.txt owner: rw-, group: r--, others: r--

Userii confundă permisiunea de execuție cu dreptul de citire. Un fișier poate fi citibil fără să fie executabil.
