C – Să reținem

  • C este un limbaj procedural, folosit mult pe Unix/Linux.
  • Programul pornește de obicei din funcția main().
  • Variabilele au tip fix: int, char, float, double.
  • printf() afișează date, iar scanf() citește date.
  • Fișierele se lucrează cu FILE *, fopen(), fgets(), fprintf(), fclose().
  • Argumentele din linia de comandă se citesc cu argc și argv.

Ghid rapid

Scopul acestui ghid este să vă ajute să înțelegeți mai ușor cum gândiți comenzile în shell scripting.

  • 1. Începeți de la problemă.
    Ce vreau să obțin?
  • 2. Gândiți input-ul și output-ul.
    Ce primește comanda? Ce produce?
  • 3. Alegeți tool-ul potrivit.
    grep, sed, awk, chmod.
  • 4. Mergeți de la simplu la combinat.
    Comandă simplă → opțiuni → pipe.
  • 5. Testați cu exemple mici.
    Mai întâi pe 3–4 linii.

Basics – ce trebuie reținut

  • Linux pornește de la root: /
  • Shell-ul primește comenzi de la utilizator.
  • Kernel-ul comunică direct cu hardware-ul.
  • stdin = input, stdout = output, stderr = erori.
  • Pipe: output-ul unei comenzi devine input pentru alta.

ls – Să reținem

  • ls afișează conținutul unui director.
  • ls -l afișează detalii.
  • ls -a afișează și fișierele ascunse.
  • ls -lh afișează dimensiuni ușor de citit.
  • În Linux, structura directoarelor pornește de la /.

chmod – Să reținem

  • chmod schimbă permisiunile.
  • r = read = 4
  • w = write = 2
  • x = execute = 1
  • 755 înseamnă owner: rwx, group: r-x, others: r-x.
  • 644 este comun pentru fișiere text.

grep – Să reținem

  • grep caută linii care conțin un pattern.
  • -i ignoră litere mari/mici.
  • -r caută recursiv în directoare.
  • -n afișează numărul liniei.
  • -v inversează căutarea.
  • -E permite regex extins.

sed – Să reținem

  • sed editează text în flux.
  • -n oprește afișarea automată.
  • p afișează linia.
  • d șterge linia.
  • s/vechi/nou/ face substituție.
  • -i modifică fișierul direct — atenție!

awk – Să reținem

  • awk lucrează foarte bine pe coloane.
  • $1 = prima coloană.
  • $2 = a doua coloană.
  • NF = numărul de câmpuri.
  • NR = numărul liniei.
  • -F setează separatorul.

  • Verifică opțiunile: -l, -a, -n, -i.
