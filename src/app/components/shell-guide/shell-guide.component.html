C – Să reținem

  • C este un limbaj procedural, folosit mult pe Unix/Linux.
  • Programul pornește de obicei din funcția main().
  • Variabilele au tip fix: int, char, float, double.
  • printf() afișează date, iar scanf() citește date.
  • Fișierele se lucrează cu FILE *, fopen(), fgets(), fprintf(), fclose().
  • Argumentele din linia de comandă se citesc cu argc și argv.

Ghid rapid

Basics – ce trebuie reținut

  • Linux pornește de la root: /
  • Shell-ul primește comenzi de la utilizator.
  • Kernel-ul comunică direct cu hardware-ul.
  • stdin = input, stdout = output, stderr = erori.
  • Pipe: output-ul unei comenzi devine input pentru alta.

ls – Să reținem

  • ls afișează conținutul unui director.
  • ls -l afișează detalii.
  • ls -a afișează și fișierele ascunse.
  • ls -lh afișează dimensiuni ușor de citit.
  • În Linux, structura directoarelor pornește de la /.

chmod – Să reținem

  • chmod schimbă permisiunile.
  • r = read = 4
  • w = write = 2
  • x = execute = 1
  • 755 înseamnă owner: rwx, group: r-x, others: r-x.
  • 644 este comun pentru fișiere text.

grep – Să reținem

  • grep caută linii care conțin un pattern.
  • -i ignoră litere mari/mici.
  • -r caută recursiv în directoare.
  • -n afișează numărul liniei.
  • -v inversează căutarea.
  • -E permite regex extins.

sed – Să reținem

  • sed editează text în flux.
  • -n oprește afișarea automată.
  • p afișează linia.
  • d șterge linia.
  • s/vechi/nou/ face substituție.
  • -i modifică fișierul direct — atenție!

awk – Să reținem

  • awk lucrează foarte bine pe coloane.
  • $1 = prima coloană.
  • $2 = a doua coloană.
  • NF = numărul de câmpuri.
  • NR = numărul liniei.
  • -F setează separatorul.

1. Overview

În shell scripting, multe probleme se rezolvă prin combinarea unor unelte simple. Gândește fiecare comandă ca pe o piesă cu un rol clar:

Tool Utilitate Întrebare
chmod schimbă permisiunile Cine are voie să citească, scrie sau execute?
grep caută linii după pattern Ce linii vrem să găsim?
sed editează textul în flux Ce vrem să transformăm?
awk lucrează pe câmpuri/coloane Ce coloane vrem să extragem sau calculăm?

Steps

  1. identific problema
  2. aleg comanda principală
  3. adaug opțiuni
  4. combin cu pipe sau redirectare

Exemplu

cat log.txt | grep -i error | wc -l

Mai bine, fără cat inutil:

grep -i error log.txt | wc -l

4. Linux FILE PERMISSIONS

chmod modifică permisiunile unui fișier sau director: cine poate citi, scrie sau executa.

chmod

1. Cum citim permisiunile

- rwx rw- r--
- tip fișier
rwx user / owner
rw- group
r-- others

2. Valori numerice

Owner

7

rwx

4 + 2 + 1

Group

6

rw-

4 + 2 + 0

Other

4

4 + 0 + 0

3. Ce înseamnă r, w, x?

rread4
wwrite2
xexecute1
-fără permisiune0

4. Mod simbolic

chmod u+x script.sh
chmod g-w file.txt
chmod o+r notes.txt
uuser / owner
ggroup
oothers
+adaugă permisiune

5. Mod numeric

chmod 755 script.sh
chmod 644 report.txt
chmod 764 backup.sh

Fiecare cifră reprezintă suma permisiunilor pentru: owner, group, others.

6. Exemple explicabile rapid

chmod +x script.sh face scriptul executabil
chmod 755 script.sh owner: rwx, group: r-x, others: r-x
chmod 644 file.txt owner: rw-, group: r--, others: r--

Studenții confundă permisiunea de execuție cu dreptul de citire. Un fișier poate fi citibil fără să fie executabil.

5. Linux GREP Cheatsheet

grep este o comandă Unix folosită pentru a căuta un pattern de text într-un fișier sau într-un flux de date.

grep

grep = g/re/p

g global /re/ regular expression p print

1. Usage

grep [opțiuni] pattern [fișier]
grep "sequence" file_1.txt
grep sequence file_1.txt file_2.txt
echo "This is a test" | grep "is"

Pattern-ul poate fi un cuvânt simplu sau o expresie regulată. grep poate căuta într-un fișier, în mai multe fișiere sau în output-ul altei comenzi.

2. Opțiuni importante

-iignoră diferența dintre litere mari și mici
-rcaută recursiv în directoare
-lafișează doar numele fișierelor cu match
-cafișează numărul de potriviri
-wpotrivește doar cuvântul întreg
-nafișează și numărul liniei
-vafișează liniile care NU conțin patternul
-Efolosește expresii regulate extinse
-A nafișează n linii după match
-B nafișează n linii înainte de match
-C nafișează n linii înainte și după match

3. Wildcard-uri

.orice caracter
?zero sau un caracter
*zero sau mai multe caractere
+unul sau mai multe caractere

4. Poziții

^început de linie
$sfârșit de linie
^$linie goală
\blimită de cuvânt

5. Clase de caractere

[A-Z]litere mari
[a-z]litere mici
[0-9]cifre
[A-Za-z0-9]litere sau cifre
[^abc]orice caracter în afară de a, b, c

6. POSIX

[:alpha:]litere
[:digit:]cifre
[:alnum:]litere sau cifre
[:lower:]litere mici
[:upper:]litere mari
[:space:]spații

6. Linux SED Command Cheatsheet

sed vine de la stream editor și este folosit pentru a transforma, filtra sau edita text direct din linia de comandă.

sed

sed = s/ed

s stream /ed/ editor

1. Sintaxă

sed [-n] [-e] 'command' [input-file]
sed 'p' employees.txt
sed -n 'p' employees.txt

Fără -n, sed afișează automat liniile procesate. De aceea, uneori pare că o linie este afișată de două ori.

2. Opțiuni importante

-nsuprimă afișarea automată
-epermite mai multe expresii sed
-fcitește scriptul sed dintr-un fișier
-imodifică fișierul direct
-Efolosește expresii regulate extinse

3. Comenzi sed

pafișează linia
dșterge linia
ssubstituie text
aadaugă text după linie
iinserează text înainte de linie
cînlocuiește linia completă
qoprește procesarea
rcitește text din alt fișier
wscrie rezultatul într-un fișier

4. Selectarea liniilor

sed -n '2p' employees.txt
sed -n '2,5p' employees.txt
sed '$p' employees.txt
sed -n '/Tudor/p' employees.txt
sed -n '/Ion/,/Victor/p' employees.txt
sed -n -e '2p' -e '5p' employees.txt

5. Ștergerea liniilor

sed 'd' employees.txt
sed '4d' employees.txt
sed '/Tudor/d' employees.txt
sed '2,10d' employees.txt
sed '/Tudor/,$d' employees.txt
sed -e '2d' -e '5d' employees.txt

6. Substituția

sed 's/Tudor/Todorutz/' employees.txt
sed 's/19/18/g' employees.txt
sed -n 's/1931/1932/p' employees.txt
sed -n 's/1931/1932/gp' employees.txt

s/vechi/nou/ înlocuiește prima apariție de pe fiecare linie. Cu g, se înlocuiesc toate aparițiile de pe linie.

7. Grupuri și backreferences

sed -n 's/\(Ion\)el/\1ut/p' employees.txt
sed -n 's/\(Vasi\)le\b/\1lica/p' employees.txt
sed -E -e 'p' -e 's/([0-9])\1$/\1\1.5/' employees.txt

Cu paranteze poți grupa o secvență și o poți refolosi prin \1, \2 etc.

8. Alte comenzi utile

sed '3a line added' employees.txt
sed '2c retired employee' employees.txt
sed '1i \t\t\t PERSONAL DATA' employees.txt
sed '5q' employees.txt
sed '3r sed_dog_and_cat.txt' employees.txt
sed -n 'w employee.bak' employees.txt

Atenție: opțiunea -i modifică fișierul direct. Este utilă, dar periculoasă la început, pentru că schimbă conținutul fără să creeze automat o copie separată.

7. Linux AWK Cheatsheet

awk este folosit pentru procesarea textului pe coloane/câmpuri, filtrare, condiții și calcule simple.

awk

1. AWK basics

awk '{print $1}' data.txt
awk '{print $1, $3}' data.txt
awk '$3 > 100 {print $1, $3}' sales.txt
awk -F: '{print $1}' /etc/passwd
awk '{sum += $2} END {print sum}' prices.txt

AWK citește linie cu linie și împarte fiecare linie în câmpuri.

2. Variabile built-in

$1primul câmp
$2al doilea câmp
$NFultimul câmp
NFnumărul de câmpuri
NRnumărul liniei curente
FSseparatorul de câmpuri
OFSseparatorul pentru output
FILENAMEnumele fișierului curent

3. Operatori aritmetici

+adunare
-scădere
*înmulțire
/împărțire
%modulo
++incrementare
--decrementare

4. Operatori de comparație

==egal
!=diferit
>mai mare
<mai mic
>=mai mare sau egal
<=mai mic sau egal

5. Operatori logici

&&AND logic
||OR logic
!NOT logic
?:operator ternar

6. Separator personalizat

awk -F, '{print $1, $4}' file.csv
awk -F: '{print $1}' /etc/passwd
awk 'BEGIN {FS=":"} {print $1}' /etc/passwd

-F setează separatorul pentru câmpuri.

7. Exemple cu condiții

awk '$3 > 100 {print $1, $3}' sales.txt
awk '$2 == "Cluj" {print $1}' students.txt
awk 'NR > 1 {print $0}' table.txt
awk 'NF > 3 {print $0}' data.txt

8. Exemple cu calcule

awk '{sum += $2} END {print sum}' prices.txt
awk '{count++} END {print count}' file.txt
awk '{sum += $2; count++} END {print sum/count}' notes.txt

AWK este cel mai util când datele au structură pe coloane. Dacă vrei doar să cauți text, folosește grep. Dacă vrei să înlocuiești text, folosește sed.

2. Basics

Arhitectura Unix

Într-un sistem Unix/Linux, utilizatorul interacționează cu shell-ul, care rulează în user space. Shell-ul transmite comenzile către kernel, iar kernel-ul comunică direct cu hardware-ul.

Structura unei comenzi

comanda [opțiuni] [valori]
  • comanda – ex: ls, cd
  • opțiuni – ex: -l, -a
  • valori – ex: fișiere sau directoare

Manual comenzi

Data Streams

Un program primește date prin stdin, afișează rezultatul normal prin stdout și afișează erorile prin stderr.

Stream Descriere
stdin (0) Input – tastatura
stdout (1) Output – ecran
stderr (2) Erori – ecran

Redirection

date > file.txt
date >> file.txt
sort < file1 > file2
  • > – suprascrie fișier
  • >> – adaugă la final
  • < – input din fișier

Pipes – legătura între comenzi

Un pipe este un mecanism de comunicare între procese (IPC). În shell, este reprezentat prin simbolul |.

  • Output-ul unei comenzi (stdout) devine input pentru alta (stdin)
  • Permite combinarea comenzilor în pipeline-uri
  • Evită folosirea fișierelor intermediare

Exemplu simplu

grep error log.txt | wc -l

Caută liniile cu "error" și le numără

Exemplu din slide

cat file1 file2 file3 | sort > dev/lp

Concatenează fișierele, sortează rezultatul și îl trimite mai departe

Greșeală frecventă: studenții folosesc fișiere temporare în loc de pipe-uri. De multe ori, un | rezolvă problema mai elegant.

De ce folosim pipe?

cat file.txt | grep error | wc -l

Combinăm comenzi simple pentru a rezolva probleme complexe.
